# Repository guidance

## Commit style

Use Conventional Commits: `type(scope)!: concise description`.

- Use lowercase types such as `feat`, `fix`, `docs`, `test`, and `chore`.
- Add a scope only when it clarifies the affected area, for example `fix(test): ...`.
- Add `!` for breaking changes.
- Keep the subject short, specific, and imperative; do not end it with a period.
- Add a body only when the rationale or operational impact is not clear from the subject. Separate it with a blank line and explain why the change is needed rather than listing files.
