# pi tower 靜態 UI 原型

直接用瀏覽器開啟 `index.html`。HTML、CSS、JavaScript 都在這個目錄，不需要安裝套件、啟動 Tower 或連線登入。

以提供的 Amp 截圖為參考，採用暖白底色、細分隔線與三欄配置：左欄依專案切換對話，中間閱讀與輸入，右欄顯示執行環境和協作紀錄。文字使用本機 Avenir Next／PingFang TC，程式碼使用等寬字型，沒有外部字型或 CDN 相依。

可操作的預覽：

- 切換對話、搜尋名稱／專案／Runner（Cmd/Ctrl + K）、查看休眠對話。
- 展開工具紀錄，切換工作環境／協作頁籤，從回報前往目標對話。
- 收合左右側欄；窄螢幕改用抽屜，支援 Escape 關閉。
- 新增示範對話、重新命名、複製預覽連結與回覆。
- 傳送示範訊息；「Runner session 計數」可預覽執行中、追加訊息、調整任務與停止狀態。
- 切換 Runner 總覽；「已休眠的對話」可預覽無法從網頁續跑的狀態。

所有 Runner 狀態、訊息與測試結果均為示範資料。操作僅影響本頁，重新整理會還原；未串接 API、WebSocket、登入或檔案操作。新建對話的預覽連結也只在本頁有效。既有 `ui.html` 和 `threads.html` 不受影響。

版面：寬度 1200px 以上為三欄，701–1199px 保留左欄，700px 以下以對話為主；右欄與手機左欄以抽屜開啟。
